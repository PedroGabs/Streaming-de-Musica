# 🎵 Sistema de Streaming de Música

## 📋 Funcionalidades

- Cadastro de usuários
- Login de usuários
- Reprodução de músicas
- Histórico de reprodução
- Sistema de playlists
- Playlist automática
- Sistema de downloads para usuários Premium
- Estatísticas do sistema

# 🏗️ Arquitetura

O projeto foi organizado em pacotes seguindo uma estrutura profissional:

src/
└── br/
    └── com/
        └── streaming/
            ├── modelo/
            ├── servico/
            ├── util/
            └── principal/

# 🚀 Como Executar

javac src/br/com/streaming/principal/StreamingMusica.java

Executar
java br.com.streaming.principal.StreamingMusica
